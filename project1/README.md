# ECE435 Project 1 - Imaging Fundamentals

This folder contains the report and MATLAB script for Medical Imaging Project 1. 

`proj1.m` includes a script that:

- Reconstructs a 3D Volume from thoracic CT slices
- Simulates imaging artifacts including salt-and-pepper noise, Gaussian noise, and anisotropic blur via PSF approximations
- Implements denoising techniques (e.g. Median, Mean, Gaussian Filters)
- Implements Canny edge detection under varying noise and blur conditions
